Small independent scalar fixture for the pre-store W4 gate. Four consecutive one-second buckets contain speed [-1, 0, 1.25, NULL], state [off, on, on, NULL], and source sets [[gps, ais], [ais], NULL, NULL]. Expected counts and values are calculated directly from these four rows, not captured from TI. These files are not claimed as DuckDB-generated outputs. The main tests/golden corpus remains the DuckDB acceptance gate.
