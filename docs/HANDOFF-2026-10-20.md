## Ground rules (Kord's standing instructions)

- **Merges and releases happen only on Kord's word.** Agents don't merge PRs. Releases default to a patch bump; 0.17.0 is an approved **minor**.
- **Ask before Rust edits, cargo builds, tests or benchmarks** unless Kord already approved that work. Docs can go straight to a PR.
- **Check CI after every push.** A local pass on a stale binary proves nothing.
- **Stage exact paths, never `git add -A`.** Never commit in a worktree with `core.autocrlf=false` without checking `git show --stat`; it once re-encoded 653 files to CRLF.
- **Never put secrets on argv, in logs or in plugin config.** The Ollama API key is sent only to ollama.com hosts.
- **No mock or fake endpoints.** Test integrations (Addita, Shivvr, Ollama) against the real running service; fixtures captured from real calls are fine.
- **Public posts and persistent changes to the Pi need Kord's OK.**
- **Spoken summaries are plain language,** at milestones and blockers only.
- **Stacked PRs merge into their base, not main.** Retarget to main before merging.
